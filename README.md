## 🧑‍💻 About Me

I'm a **self-taught DevOps Engineer** focused on taking applications from source code to **live, containerized deployments** on the cloud.

My core toolkit includes **Docker, AWS (EC2, ECR, ECS Fargate), Oracle Cloud (OCI), and GitHub Actions**, with hands-on experience across the full delivery lifecycle — containerizing apps, pushing images to registries, deploying to cloud infrastructure, and automating builds. I learn by building: every project here is a real deployment, not just a tutorial.

### 🎯 What I Do

🐳 **Containerization**

- Dockerfiles for Next.js, FastAPI and Node.js apps
- Image builds, tagging and publishing to Docker Hub & Amazon ECR
- Multi-service setups with Docker Compose

☁️ **Cloud Deployment**

- AWS EC2 deployments within free-tier limits
- AWS ECR + ECS Fargate container deployments
- Oracle Cloud (OCI) live deployments for full-stack apps

⚙️ **CI/CD & Automation**

- GitHub Actions pipelines for build, test and deploy
- Git repository setup, branching and workflow configuration
- Repeatable, documented deployment steps

🐧 **Linux & Server Management**

- Server setup, SSH access and security groups
- Reverse proxy, ports and networking basics
- Debugging failed deployments and container logs

### 💡 What Sets Me Apart

- End-to-end ownership: code → container → registry → cloud → live URL
- Real deployments on multiple clouds (AWS and Oracle Cloud)
- Clear documentation and step-by-step, repeatable processes
